Loadout strategy

Five saved builds make route changes faster

Reviewed 7 August 2026 · Matches the current equipment system

Set means loadout, not a matching-item bonus

The five Set buttons save different combinations of equipped gear. Wearing similarly named pieces does not activate a hidden set bonus. Judge every loadout by its combined HP, ATK, DEF, AGI, LUC, and special effects.

A useful starting layout is one balanced build, one boss-survival build, one fast farming build, one drop-focused build, and one experimental slot. Adapt those roles to the items and characters you own.

Build for the next problem

Use the item catalog to find known drop and shop sources, then save combinations that answer different enemies. More HP and DEF can stabilize a dangerous boss; ATK and AGI can shorten safe farming; LUC and drop effects help collection runs.

Permanent collection bonuses still apply outside the currently equipped loadout. Duplicate items can therefore improve long-term power even when none of your five saved builds equips that item.

Before switching

Check the selected Set number and its total stats before entering a boss area. Switching to the wrong saved loadout can trade away the survival or damage the route requires.
